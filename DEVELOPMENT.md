# AIbotURFU: быстрый старт для разработчиков

Учебный чат-бот на Python и обычных HTML/CSS/JS. ИИ — готовая **Qwen3 8B через Ollama**, поиск по документам пока лексический. Дообучения, embeddings и векторной базы нет. Подробности функций — в [README.md](README.md).

## Установка и запуск (Windows PowerShell)

Нужны Git, Python 3.10+ и [Ollama](https://ollama.com/download). Для локального ИИ API-ключ не требуется. Node.js и сборка интерфейса не нужны.

```powershell
git clone https://github.com/TimofeyChugunov/AIbotURFU.git
cd AIbotURFU
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Запустите Ollama, затем скачайте модель и запустите сайт:

```powershell
ollama pull qwen3:8b
.\start-local.cmd
```

Чат: http://127.0.0.1:3000, регистрация: `/auth`, материалы администратора: `/admin`. Остановка — Ctrl+C. Для повторного запуска достаточно Ollama и `.\start-local.cmd`.

Чтобы загружать документы, перед запуском задайте свой пароль администратора в том же терминале:

```powershell
$adminSecret = Read-Host 'Пароль администратора' -AsSecureString
$env:ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', $adminSecret).Password
```

Для разработки интерфейса без модели используйте явно обозначенный деморежим:

```powershell
$env:AI_MODE = 'demo'
.\.venv\Scripts\python.exe server.py
```

`start-local.cmd` всегда выбирает Ollama и `qwen3:8b`, поэтому для демо запускайте Python напрямую. `.env` автоматически не читается.

## Где что менять

| Файл | Назначение |
| --- | --- |
| `server.py` | HTTP API, документы, SQLite, инструкции ИИ |
| `local_ai.py` | Подключение Ollama и контекст модели |
| `retrieval.py` | Разбиение текста, поиск и уточнения вопросов |
| `docx_review.py` | Приватные DOCX: разбор, проверка привязок замечаний и экспорт комментариев Word |
| `docx_fonts.py` | Определение заданных шрифтов по символам, стилям и теме DOCX |
| `accounts.py` | Регистрация, пароли и сеансы |
| `public/` | Чат, админка, авторизация и темы |
| `tests/` | Автоматические проверки |

Путь запроса: вопрос → поиск фрагментов → контекст для модели → ответ с источниками. Общие вопросы работают без документов. Для проверки поиска загрузите свой PDF с текстовым слоем, DOCX или TXT через `/admin`.

База `data/materials.sqlite3` создаётся автоматически и содержит документы, аккаунты и сеансы. История чатов хранится в браузере. Рабочая база, модель и секреты не входят в Git; для разработки создайте свои тестовые данные.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

С работающей Ollama и `qwen3:8b` дополнительно:

```powershell
.\.venv\Scripts\python.exe tests/dialogue_smoke.py
.\.venv\Scripts\python.exe tests/ollama_smoke.py
```

Проверки используют временные базы. Первые работают без реального ИИ, последние проверяют настоящий диалог и ответ по документу.

## Дальнейшая работа

1. Собрать тестовые вопросы с ожидаемыми ответами и источниками; зафиксировать качество и время ответа.
2. Улучшить RAG: метаданные страниц и версий, постоянный индекс, embeddings, гибридный поиск и reranking. Обновлять индекс при изменении документов.
3. По результатам оценки решить, нужно ли дообучение. Ollama здесь запускает модель; обучение потребует отдельного инструментария и датасета.
4. Подготовить серверное размещение: HTTPS, домен, сеансы, очередь запросов и резервные копии.

Сейчас приложение доступно только локально, адрес Ollama фиксирован в `local_ai.py`, одновременно выполняется одна генерация. Для общего сервера ИИ потребуется настройка адреса и защищённого доступа. Готовой конфигурации публичного размещения нет.

Работайте в отдельных ветках и передавайте изменения через Pull Request. В Git не добавляйте `data/`, модели и секреты.
